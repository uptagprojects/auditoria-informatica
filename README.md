# Auditoría Informática — Material de Estudio

Repositorio con el material de estudio de la materia **Auditoría Informática**.
El enfoque no es teórico: cada documento explica **cómo auditar** un dominio concreto
(qué evidencias pedir, qué pruebas ejecutar, qué herramientas usar y cómo documentar hallazgos).

## Contenido

| Carpeta | Tema | Descripción |
|---|---|---|
| [`2-areas_especificas`](./2-areas_especificas/README.md) | Áreas específicas de auditoría | Gobierno TI, SDLC/Agile y gestión de cambios, infraestructura (Data Center, DRP/BCP, SSOO, redes), ciberseguridad (IAM, criptografía, pentesting) y bases de datos. |

## Cómo usar el material

1. Empezar por el **marco común** (pilares de auditoría, técnicas, escala de hallazgos) del documento de áreas específicas.
2. Estudiar cada área con la estructura: *concepto corto → cómo auditarlo → puntos clave → casos concretos → herramientas → evidencias*.
3. Usar el **checklist transversal de cierre** para validar que todo hallazgo tenga criterio, condición, causa, efecto y recomendación.

## Convenciones del material

- Los diagramas están escritos en **Mermaid** y se renderizan en visores compatibles (GitHub, GitLab, VS Code).
- Los hallazgos se clasifican por severidad: **Crítica**, **Alta**, **Media**, **Baja**.
- Toda conclusión debe apoyarse en evidencia **suficiente, competente y trazable**.

## Requisitos

No se requiere instalar nada para leer el material. Para visualizar los diagramas Mermaid
se recomienda abrir los archivos en GitHub, GitLab o en un editor con soporte de Mermaid.
